# MinionsParadiseServer

Servidor experimental para o projeto MinionsParadiseBrazil.

## Requisitos

- Windows
- Python 3.8
- Conexao de rede local

## Como iniciar

1. Instale o Python 3.8.
2. Execute start.bat.
3. Aguarde a instalacao das dependencias.
4. Acesse http://localhost:8000.

## Endpoints

- GET / - Informacoes do servidor
- GET /health - Verificacao de funcionamento
- GET /config - Configuracoes experimentais
